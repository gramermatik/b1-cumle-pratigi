# B1 Cümle Pratiği

Öğrenciler için basit bir B1 İngilizce pratik uygulaması.

- **Çoktan Seçmeli:** Türkçe cümlenin doğru İngilizcesini seç.
- **Cümle Yaz:** Türkçe cümleyi İngilizceye çevir. Her cümlenin 2-4 kabul edilen çevirisi var; kısaltmalar (I'm / I am), büyük-küçük harf, noktalama, İngiliz/Amerikan yazımı ve 1-2 harflik yazım hataları sorun olmaz.
- **Kelime Testi:** Oxford 3000 listesindeki 809 B1 kelimesi.
- **Gelişimim:** Doğru bilinen cümle/kelime sayısı, başarı yüzdesi, son turlar ve tekrar edilmesi gerekenler. Yanlışlar sonraki turlarda tekrar sorulur. İlerleme öğrencinin kendi tarayıcısında saklanır.

## GitHub Pages ile yayınlama
1. Bu klasörü bir GitHub deposuna yükle.
2. Depoda **Settings → Pages → Branch: main / (root)** seç, kaydet.
3. Birkaç dakika sonra link hazır: `https://KULLANICI.github.io/DEPO-ADI/`

## Cümle eklemek
`data/sentences*.js` dosyalarına şu biçimde satır ekle:
`Türkçe cümle|English answer 1|English answer 2|English answer 3`
